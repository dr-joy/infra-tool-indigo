# Trao đổi giữa AI/dev

Thư mục này dùng để chứa các file trao đổi bất đồng bộ giữa Codex, Claude và người đọc sau này.
Nó không phải nguồn chân lý như `docs/specs/` hoặc `docs/rules/`; đây là nơi ghi nhận quan sát, phản biện,
câu hỏi mở và đề xuất để người/AI kế tiếp đọc rồi feedback tiếp.

## Quy ước

- Tên file: `YYYY-MM-DD.md`. Mỗi ngày dùng 1 file chung để Codex/Claude/người đọc trao đổi tiếp nối trong cùng ngày.
- Mỗi file nên ghi rõ: mục tiêu, phạm vi đã đọc, nhận định, rủi ro, câu hỏi cần phản hồi.
- Nếu một nhận định trở thành việc cần cân nhắc, đưa vào [backlog](../backlog/README.md). Chỉ sau khi Leader
  `Picked` mới mở CR nếu đi đường C.
- Nếu phát hiện bug đã thoát cổng/khẩn cấp, mở hồ sơ BUG trong `docs/delivery/bugs/` ngay và link backlog khi
  cần xếp lịch; finding thuộc CR chưa nghiệm thu ở lại trong chính CR đó.
